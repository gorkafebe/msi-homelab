- Project: <https://github.com/arpanghosh8453/garmin-grafana>, © 2025 Arpan Ghosh.
- Commit: `2e9ecadbb59cd1ee6706d7010710ed3a5ceb27f6` (2026-11-25).
- Copied unchanged into [`stacks/garmin/vendor/garmin-grafana/`](stacks/garmin/vendor/garmin-grafana/):
  `Garmin-Grafana-Dashboard.json` and the project's `LICENSE` (hashes in `SOURCE.md` there).
- **Derived file:** [`stacks/garmin/dashboards/garmin-stats.json`](stacks/garmin/dashboards/garmin-stats.json),
  generated by [`scripts/vendor-dashboard.py`](scripts/vendor-dashboard.py). Modifications:
  1. The datasource input `${DS_GARMIN_STATS}` is replaced by the provisioned uid `garmin-influxdb`
     (202 references: 58 on panels, 144 on queries).
  2. The export blocks `__inputs` and `__requires` are removed.
  3. Removed: the three `geomap` panels ("GPS Track by Velocity", "GPS Track by Heart Rate",
     "Heatmap for GPS Activity"), because their base maps are tiles that the browser downloads from
     an external map service.
  4. Removed: the "Support Me!" text panel, because it loads an image from an external site. The
     author's project is credited here and in the README; please support it upstream.
  5. Converted: "Hourly walk heatmap" and "Sleep Regularity", which use the
     `marcusolsson-hourly-heatmap-panel` plugin, are rebuilt as Grafana's built-in `heatmap`
     panel (no plugin download). The view differs: upstream shows hour of day against day; the
     built-in panel shows day against buckets of the hourly value (description on each panel).
  6. Fixed uid (`garmin-stats`), title, tags; `id` and `version` reset for provisioning.

copied files and by not using the author's name to promote this project.
